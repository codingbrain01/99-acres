# Delhi NCR Property Leads

Single-page React/Vite lead capture site for rent, sale, rent-out and buying requirements across Delhi NCR.

## Features

- Hero section with real estate visual and WhatsApp call to action
- Rental, owner and buying requirement forms
- Form submissions open WhatsApp with prefilled lead details
- Delhi NCR coverage and trust sections
